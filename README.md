# Projeto do kml-dms-converter
O APP foi desenvolvido em HTML para ser simples, sem a necessidade de armazenamentos de dados, realizando todo o procedimento pelo navegador.
A funcionalidade foi pensada para converter as coordenadas de arquivos KML (Keyhole Markup Language) para formato DMS (Graus, Minutos e Segundos - Degrees, Minutes, Seconds).
Ao carregar o arquivo KML também há opção de visualização em tabela para conferência dos dados gerados e possibilita o download das coordenadas geradas em .txt, formatos para excel e html da tabela para uso em programas como o QGIS.

A aplicação visa acelerar a geração das coordenadas do poligono criado para posterior uso em relatórios, memoriais descritivos e também possibilita o uso das coordenadas para requerimento mineral junto a ANM - Agência Nacional de Mineração.
